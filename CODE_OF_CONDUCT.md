# Code of conduct

This project adopts the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its
code of conduct. It applies to everyone taking part in the project, in every
project space: issues, pull requests, discussions, and any other channel
where you represent the project.

The text of the Covenant is not copied here; the link above is the
authoritative version.

## Reporting

Report unacceptable behaviour privately to the project maintainer,
[@AndrewSillifant](https://github.com/AndrewSillifant) on GitHub. Reports are
handled in confidence. Enforcement follows the Covenant's [enforcement
guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
